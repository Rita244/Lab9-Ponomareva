
## Контрольные вопросы

1. С 0

2. Length - 1

3. При i <= Length на последнем шаге i станет равен Length — такого индекса нет, будет ошибка IndexOutOfRangeException. i < Length не выходит за границы

4. for — когда нужен индекс (номер, изменение, соседние элементы)
foreach — когда нужен только сам элемент (сумма, поиск, вывод)

5. Массив — ссылочный тип. В метод копируется ссылка на тот же массив, поэтому меняются его элементы
6. 0 может не быть в массиве и дать неверный результат (числа отрицательные — максимум станет 0). Первый элемент точно принадлежит массиву

7. Ничем, оба создают массив. [...] — новый синтаксис (C# 12+), {...} — старый. Работают одинаково

Необязательный вопрос для любознательных: с ref int[] array можно переприсвоить саму ссылку, это будет видно снаружи. Без ref меняются только элементы, а не ссылка
